# 小祈桌宠与菜单 · 预览和功能核对

日期：2026-11-20。交互预览：http://127.0.0.1:17949/ ，功能表：http://127.0.0.1:17949/audit.html 。

本轮只在 design-previews 生成预览文件。没有修改 Unity 源码、Tonight 包、个人配置、系统启动项，也没有发起真实对话、屏幕分享或麦克风采集。Ctrl+N 已按用户选择规划为全局接管，但尚未注册到 Windows。

## 桌宠的定位与视觉

常驻时显示角色与一个 36px 的猫耳轮廓按钮；勿扰用这个按钮上的月亮徽标表达，取消头顶的孤立“安静中”。靠近后展开打字、按住说话、形态三枚按钮。形态列表点击后才出现。菜单打开时暂时收起快捷按钮，减少同时出现的操作区。

语音只保留一块有边界的状态，不再在人物头顶堆出多轮对话。录音、识别、思考互斥；回复默认短气泡，可展开这条；失败说明“未识别到文字，本次未发送”，提供重新录音和打字。错误不是小祈说的话，不使用夸张亮粉长条。字体、底色、细边框、轻阴影沿用近景的奶白灰紫调。没有给桌宠加姓名大标、第二个 Q 版人像或全屏底板。

当前两块屏幕均为 1920×1080，工作区高度 1032，副屏坐标 (-1920,-680)。默认以角色高度 364px 排版；UI 尺寸独立，不跟着角色缩小。1366×768 的额外原尺寸检查仍保留相同文字与角色尺寸，不把整幅画缩小来假装适配。

## 一、二级菜单

1. 说说话：打字、按住说话 Ctrl+N、分享当前窗口标题。现版不等于截图理解，名称写清能力。
2. 和她互动：摸头、换姿势、小睡 / 叫醒、选舞。选舞复用二级面板并提供返回，不再横向增加第三层。实际动作应仅列出可执行 ID。
3. 桌面位置：当前屏幕归位、离开窗边；长期自动坐窗口转去偏好设置。未坐窗口时，离开按钮禁用并说明。
4. 声音与勿扰：短期勿扰、小祈的声音开关、声音设置。结束勿扰不会假装同时解除静音，分别写清状态。

顶部当前生活状态是展示，增加显式“今天”按钮；底部偏好设置单独打开六页设置。连接、密钥、开机启动不占快捷菜单。

## 功能审计与待实施顺序

audit.html 为可筛选的 38 项清单，menu-audit.json 为同一数据。每项包含目前行为、证据与处理方案。“已接线”只代表源码存在调用路径，不等同系统动作/真人录音已验收。

先修真实性：组合键识别和全局拦截、录音取消规则、状态样式复位、气泡与 TTS 解耦、坐窗口单一配置源、真实连接检测、舞蹈去重及能力判断。再统一展示：语音/HUD/HeadAnchor 的状态所有权、角色边缘锚点、菜单层级与条件说明。最后做实际真人语音、五支内置舞蹈、模型重载、多屏负坐标和设置重启持久性验收。

Ctrl+N 在浏览器只做页面内按住 / 松开 / Esc 的状态演示。Windows 实现需真正阻止其它应用触发这组快捷键，处理重复按键、注册/钩子失败、释放丢失、切形态、失去录音设备与退出时取消。不能只把配置从 N 改成 Ctrl+N。尚未决定的全模式覆盖范围应在实施时遵守桌宠/近景现有语音入口，避免两个入口同时采集。

全局快捷键、服务地址、开机启动等属于设置工作，不是 UI 图能证明的能力。本稿不会把预览动画当成功能完成。

## 复现与限制

serve.cjs 启动本地只读服务，render.cjs 生成状态、菜单和 1920 全图，verify.cjs 检查左边缘、独立静音状态与 1366 原尺寸排布。checks.json、layout-checks.json 是检查结果。

人物来自现有 Tonight VRM，使用 Three.js 作构图占位，浏览器的材质和静止姿势不代表 Unity 实机。控件使用普通布局、圆角、边框与轻阴影，不依赖实时背景模糊、圆角裁切或新动画素材。Unity 落地时需保持透明窗口的圆角容器不设 Overflow.Hidden，主相机 rect 保持全屏；窗口空白区域仍需穿透。

语音状态图使用示例文字；不会连接上游。舞蹈按钮不执行动作。记录中旧 TTS 成功是前次集成证据，真人麦克风识别尚未通过验收，不能将这两件事混为一谈。
