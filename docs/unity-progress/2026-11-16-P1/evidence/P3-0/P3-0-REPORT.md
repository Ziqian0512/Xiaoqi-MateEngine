## 2. 怎么起的
- 假接口：在下载副本目录 `/workspace/p3-0/repo` 里执行 `python3 tools/mock_body_api.py --port 8911`，没有改任何文件。mock 自己用 `/p/bench` 提供页面，没有用 console_v2 或 relay。模式通过 `GET /mock/mode?to=data|empty|offline` 切换，也就是 mock 自带的接口。
- 页面网址：`http://127.0.0.1:8911/p/bench#t=mock&theme=<pink|blue|violet>`。令牌只用假令牌 `mock`，401 用例用的是一个错误的假串。
- mock 服务端日志里只有 `GET /p/bench`，没有 `#t=`：片段确实没有发到服务器。
- 参照图：`docs/ui-kit/XQ_样式稿_桌宠_近景_工作台_20261116.html`（main）用 `python3 -m http.server` 在本地提供，以 `?only=p3&nomk=1`、viewport 1920×1080 打开后截图。这就是样式稿里写的「标准图导出」方式。

> **注意：比对用的不是 `docs/ui-kit/std/P3_工作台_纯净.png` 原文件，而是用同一导出方式重新渲染出来的。** 原因是 PNG 原文件拿不到：

> - 目录列表里的 download_url 带有临时令牌，按规矩不用；

>
> 重渲染图 825,058 B，原图 838,948 B，两者都是 1920×1080，差异可能来自字体，未逐像素核对。因此「与原 PNG 完全一致」这一点**无法验证**。如需用原图复核，请把原 PNG 发给我，或在办公室电脑上批准读取。

## 7. console 错误
- data、empty、search：console 0 条，失败请求 0 个。
- offline：每轮 3 条「Failed to load resource … 503」。
- 401：每轮 3 条「… 401」。
- 断网：3 条 net::ERR_FAILED。
- 这些都是浏览器对失败请求的默认报错，没有 JS 异常（pageerror 0 条）。详见 P3-0-console-network.log。
