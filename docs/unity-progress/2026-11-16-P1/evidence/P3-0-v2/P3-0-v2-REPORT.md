## 2. 怎么起的
- `python3 tools/mock_body_api.py --port 8911`，在下载副本里原样运行，页面由 mock 的 `/p/bench` 提供。网址 `/p/bench#t=mock&theme=…`，只用假令牌 `mock`；401 用例用的是一个错误的假串。
- 两种断线：
  - **503**：mock 自带的 `/mock/mode?to=offline`，恢复用 `?to=data`；
  - **网络断**：停掉 mock 进程（连接被拒），恢复时在同一端口重新启动 mock。
- 重启时 mock 自己的「端口占用」检查连续拒绝启动，因为 Linux 上浏览器的连接还停在 TIME_WAIT。我的脚本每秒重试一次，**55.2 s 后才成功**。这是 mock 启动探测的行为，与页面无关。
- 参照图沿用第一轮：样式稿 `?only=p3&nomk=1` 在 1920×1080 下重新渲染，网页区裁剪框 **x 140–1780、y 380–1060**。和原 `P3_工作台_纯净.png` 是否逐像素一致仍**无法验证**，原因同第一轮：原 PNG 二进制无法通过 MCP 取得。
- 工具：Python 3.13.5、playwright 1.65.2、Chromium headless 159.0.8154.6、Pillow 13.0.0、字体 Noto Sans CJK SC。
