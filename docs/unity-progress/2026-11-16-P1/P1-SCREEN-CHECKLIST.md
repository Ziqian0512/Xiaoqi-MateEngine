# 屏幕前清单（谁坐在 INORI02 前面，就照这张做）

> 作者：WB　日期：2026-11-16　用途：把「只有人在屏幕前才能验」的事合成一张，**一次做完，约 20 分钟**。
> 前提：`xiaoqi/int-d1`（或之后的 `xiaoqi/wb-b6`）已经编过。**屏幕别锁**，Win+L 之后截图是全黑的。
> 每项写「通过 / 没通过 / 无法验证」+ 一句话现象，**不要编「通过」**。证据放 `evidence/` 下。
> 日志位置：`%LOCALAPPDATA%\Xiaoqi\brain.log`；`player.log` 在 `%USERPROFILE%\AppData\LocalLow\<公司>\<产品>\Player.log`。

## A. 先开两个窗口备用

- 记事本（点击穿透要用）。
- 任务管理器或随便什么，用来确认进程在。

## B. 第一轮：B1 的 8 项（G61-A §3.2，细节以那份为准）

| # | 项 | 一句话怎么验 |
|---|---|---|
| 1 | 点击穿透 | 点气泡不影响记事本；点透明处能点到记事本、能打字 |
| 2 | 主题 | `-xq-theme blue` 整体变蓝 |
| 3 | 跳舞 | 右键 → 让她… → 跳舞 → 舞 1–5 各点一次，2 秒内变、一直跳；点「停」或拖她能停 |
| 4 | 睡姿 | 睡一会 → 叫醒；睡一会 → 拖醒；坐窗口时睡一会（先下窗再睡） |
| 5 | 菜单 | 「自己走 / 停下」没了，其余不错位 |
| 6 | 全屏躲开 | 全屏视频：她消失；退出：回来、位置不变、不抢焦点；记事本最大化不躲 |
| 7 | 桌宠界面 | 8 秒无操作胶囊淡出，鼠标靠近淡入；方钮展开三药丸；单击她出今天卡 |
| 8 | 旧功能 | 拖拽、落任务栏、拖到窗口顶边坐下、窗口关了掉下来、下窗、变小/恢复、说句话、双击摸头、回到中间、窗口保护、启动卡、托盘退出 |

## C. 第二轮：B3 动作自由（P1-4b/c）

先用 `Xiaoqi.exe -xq-brain-fast` 启动（换待机间隔 3–6 秒，不然要等很久）。

| # | 看什么 | 通过标准 |
|---|---|---|
| C1 | 站着看 60 秒 | 每次换动作是**一次干净的淡入（0.4–0.8 秒）**，没有「滑过好几个姿势」的怪帧；头不抽、脚不滑 |
| C2 | 同一条会不会立刻重复 | 连看 10 次切换，没有「A→B→A」立刻回头 |
| C3 | 鼠标在她身上停 0.5 秒 | 出一个开心的小表情，**没有声音**；20 秒内再停不重复 |
| C4 | 拖她、放下 | 放下后 8 秒内不乱换；`brain.log` 有 `evt=drag_end` |
| C5 | 睡着 / 跳舞时 | 不换待机；`brain.log` 里没有这段时间的 `evt=idle`，有 `evt=skip reason=asleep/dancing` |
| C6 | `brain.log` | 跑 10 分钟（不带 fast 参数）≥ 20 行，每行有 `src=`；数一下 random / local 各多少 |

要是 C1 里有「抽一下」或「手突然甩开」：录屏，**别自己改**，WB 来调（`XqPoseBlend` 的淡入时长和跳过的骨骼）。

## D. 第三轮：B6 托盘与状态（分支 `xiaoqi/wb-b6` 编过后）

| # | 看什么 | 通过标准 |
|---|---|---|
| D1 | 托盘右键 | 顺序：隐藏小祈 / 静音 / 安静一小时 / ———— / 小祈设置 / 退出小祈 |
| D2 | 点「隐藏小祈」 | 她消失；托盘变「显示小祈」；点了她回来；全屏进出不会让她提前出现 |
| D3 | 点「静音」 | 文字变「取消静音」；放个声音（或 ME 的舞蹈音）确认无声 |
| D4 | 睡着了 | 只留一个胶囊「睡着了 · 宿舍」，其余淡出；Zzz 气泡出现一次 |
| D5 | 安静一会 | 头顶只有一行「安静中 · 到 HH:MM」，没有气泡没有胶囊 |
| D6 | 她外出了 | `-fake-stage walk_in` 之类：只有一个胶囊「她出门了 · 约 HH:MM 回来」 |
