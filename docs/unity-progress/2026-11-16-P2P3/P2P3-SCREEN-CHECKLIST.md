> 前提：Grok 已在 INORI02 上把 `xiaoqi/p2` 编过（编译错误只让他修编译错，不改逻辑）。
> 测试用启动参数：`-xq-mode close` / `-xq-mode bench -xq-bench`（无人值守切一次）、`-xq-hotkeys`、`-xq-bench`（打开工作台入口）。

## 近景（P2）

| 编号 | 做什么 | 看什么 |
|---|---|---|
| F1 | 右键她 →「让她…」→「近景」 | 窗口铺满、镜头推向头部，约 1 秒走完；日志有 `XQ_MODE Pet -> Close` |
| F2 | 近景里按 `Esc`（先点一下她让窗口拿焦点）| 回到原来的位置和大小，不漂移；连续 3 轮 |
| F3 | 近景里点透明处 | 能点到下面的窗口（穿透）—— **这条是最大风险**，ME 大屏模式可能不穿透 |
| F4 | 近景里右键她 | B2 菜单还能出，里面有「桌宠」 |
| F5 | 日志 | 有 `XQ_EVENT view close`；服务器已部署 E1c 时 `body_log` 里有 `view` 行 |
| F6 | 近景的取景 | 眼睛约在屏高 43%（粗看）；不对就调 `xq_mode.json` 的 `close_zoom` / `close_yoffset` |

## 工作台（P3）

| 编号 | 做什么 | 看什么 |
|---|---|---|
| G1 | 带 `-xq-bench` 启动 → 菜单「工作台」 | 弹出 Edge 窗口，位置约在屏幕左 7% 上 30%，约 85%×68%；日志 `XQ_BENCH placed before/after/want` 三个值贴出来（100% 与 175% 各一次）|
| G2 | 她 | 约 1 秒内坐到窗口标题栏上沿，水平约 49%，不压右上角三个按钮；日志 `XQ_BENCH sit ok=True` |
| G3 | 拖窗口 | 她跟着走，肉眼不掉队；录屏 |
| G4 | 点网页卡片；点她身体 | 各自正常（网页点得到；点她是她的反应）|
| G5 | 最小化 → 还原 | 她下窗，还原后 1.5 秒内坐回；最大化时站任务栏，不抖 |
| G6 | 关闭窗口 | 她回到进入前的位置和大小；日志 `XQ_BENCH closed` + `XQ_MODE Bench -> Pet`；3 轮不漂移 |
| G7 | 工作台里把她拖走 | 松手 1.5 秒后她又坐回去 —— **主人定要不要这个行为**（见 FACTS-P3-2a 方案第 3 点）|
| G8 | 任务管理器结束 Edge | 回桌宠不报错 |
| G9 | 工作台期间别的程序全屏 | 她藏，Edge 窗口**不会**藏（已知缺口，记一下现象）|
